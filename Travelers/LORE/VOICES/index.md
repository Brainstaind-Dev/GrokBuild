# The Voices

**"There are 13… or 14… or more. The number is not fixed. The world is still counting."**

This page is the living registry of every distinct musical identity that has emerged since the First Fracture. Each Voice is a way the broken zi learned to sing again.

**To add a new Voice:**
1. Copy `TEMPLATES/VOICE-TEMPLATE.md`
2. Create `LORE/VOICES/[Name].md`
3. Fill it using the template
4. Add an entry to the table below with a link
5. Update any related Voice or Species pages with cross-references
