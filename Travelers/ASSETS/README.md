## How to Reference Assets in Lore Entries

Always use full paths relative to the master library, e.g.:

- `I:\art\Travelers\YouTube\Teller\RSS\Escape.mp3`
- `I:\art\Travelers\rendagead.png`
- `I:\art\Travelers\Klos\Teller\Teller.png`

This keeps the bible grounded in what actually exists while allowing the lore to grow ahead of the assets when needed.
