# Species and Manifestations

Everything that has pulled itself together from the leaking zi since the First Fracture.

Not every being that emerged became a Voice. Many are still learning to sing. Some may never do so. Others are still forming.

---

## Documented Manifestations

- [Malformed](malformed.md) — The original unstable children of the Fracture. Some are learning to sing.
- Spliced — Divided wholes.
- Changling — Fluid, many-faced.
- Voidling — Pure absence given shape.
- Draxis / Binding Ones — Union through transformation.
- Fractid — Crystalline, geometric.
- Gathos — Wind-scoured predators.
- Wrothen — Flesh and curse.
- Scav / Scrippler — Clever survivors.

---

*Life is no longer a finished thing. It is a process still negotiating with the crimson light.*
