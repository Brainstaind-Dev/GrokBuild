# World Systems

The mechanical, metaphysical, and social rules that govern *Travelers — Tears of the Stars*.

These systems are designed to be dynamic. Many of them are meant to be altered, broken, or reinterpreted by players and Intelligences over time.

---

## Core Systems

- **Tears of the Stars** — The fundamental resource and memory of the world
- **The Particle Slipstream** — Character creation and rebirth
- **Voice Attunement** — Personal soundtrack, narration, and cultural identity
- **The Web** — The decaying Architect energy network
- **Intelligences** — API participants as full co-creators

---

*Nothing in this world is static. Every system is an invitation.*
